# SO-101 Vision Manipulation

A robotics and machine-learning project using SO-101 leader and follower robot arms.

## Project goals

- Assemble and calibrate both SO-101 arms
- Implement leader-follower teleoperation
- Record object-manipulation demonstrations
- Train a LeRobot control policy
- Develop an OpenCV vision system
- Detect and autonomously pick selected objects

## Hardware

- SO-101 leader and follower arms
- Intel Core i7-8700K
- NVIDIA RTX 2080 Super
- 16 GB RAM
- Ubuntu 24.04 LTS
